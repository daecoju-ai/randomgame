# 학습 / 오늘의 학습: 최소 저장 구조 (V52)

## 저장과 출제
문제·정답·해설·교육과정·출처·라이선스는 GitHub `data/`에만 저장한다. 빌드 시 학교급/학년/과목별 정적 팩으로 분리하고 선택한 팩만 브라우저에서 읽는다. 무작위 출제하며 현재 화면에서 직전 문제만 피한다. 오답 가중치, 풀이 횟수, 정답률, 문제별 숙달 기록은 저장하거나 사용하지 않는다.

현재 초1 수학 3문제, 초3 수학 3문제, 일반 영어 문장 1개가 시범 reviewed 팩이다. 정식 published 검수는 별도다. 초1 계산은 10 이하 덧셈/뺄셈/수 순서 자체 문항이며 교과서나 공식 문구 복제는 하지 않았다. 다른 학년·과목은 준비 중이다. 기본 프로필 저장은 선택 사항이며 학년·분야는 언제든 바꿀 수 있다.

Supabase에 영구 유지하는 학습 정보는 기본 선택 프로필, 최근 요청 UUID의 순서 확인값, 오늘 과목별 첫 보상 여부다. 기존 재화 지갑을 재사용한다. 보상 검증용 세션은 사용자당 한 행만 유지하며 새 학습에서 교체한다. 진행 중에는 문제 ID/정답 접두부 해시가 필요하지만 완료 즉시 비운다. 완료 후에는 지급 결과와 해당 시도의 오답 수만 유지한다. 지난 문제별 통계는 제거하고 신규 저장도 중단한다. 문제 수와 반복 횟수에 따른 학습 기록 누적은 없다. 사용자 수 증가에 따른 용량 증가는 남는다.

## 재지급 방지
클라이언트는 시간순 UUIDv7 시작 ID를 생성한다. 서버는 프로필 행 잠금과 최근 시작 ID의 high-water mark를 사용해 이미 교체된 시작 요청을 거부한다. UUID의 시간은 최근 2시간~미래 5초 범위에서 검증한다. 최신 완료 요청을 재전송하면 같은 결과를 반환하지만 지갑은 갱신하지 않는다. 최신 요청보다 이전 ID로 다시 start/finish할 수 없다. 새 세션마다 서버가 타일 정답을 검증하며 영어는 듣기 이벤트와 1초 이상 경과를 요구한다. 브라우저의 실제 음성 청취나 인간 플레이 자체를 증명하는 기술은 아니다.

사용자당 동시 학습은 한 건이다. 다른 기기/탭에서 새 학습을 시작하면 이전 진행은 종료된다. 오래된 v4 시작 요청은 새로고침 안내로 거절한다. 기존 진행 중인 최신 v4 세션의 finish는 유지한다. 플레이 중단 데이터는 해당 기기 로컬 저장소로 복구한다.

수학/영어 각각 KST 하루 첫 완료 30금화+1다이아, 이후 새 세션 완료마다 1금화. 횟수 제한은 없다. 과거 날짜의 첫 보상 플래그는 다음 지급 때 지운다. 세션을 통째로 무조건 삭제하면 중복 지급 문제가 생기므로 high-water mark를 유지한다.

## API 문제은행 작업
`python3 scripts/import-learning-reference.py krdict 사과 --output .learning-staging/apple.json`
또는 `stdict`로 실행한다. 서버/편집 환경의 KRDIC_API_KEY 또는 STDICT_API_KEY만 사용한다. 10개 이하 텍스트 참조자료를 검수 전 임시 위치에 확보하고 메타정보/체크섬/확인일을 기록한다. 이미지/음성/영상은 가져오지 않는다. .learning-staging은 Git에서 제외된다.

자료 확인 → 이용조건 확인 → 자체 문제/해설 작성 → `data/questions/`의 draft → 검수 reviewed → published 순서다. API 참조를 문제 본문으로 자동 복제하거나 자동 공개하지 않는다. sources.json/licenses.json에서 출처와 조건을 연결하고 기존 validation script를 실행한다. 새 출제 문항은 서버 fingerprint 허용목록도 갱신해야 한다. 법령은 법령명/조문/시행일/확인일/버전을 검수하며 Q-Net은 시험 메타데이터로만 사용한다. 법령·Q-Net 다운로드 어댑터는 아직 없다. 승인키 미등록으로 외부 API 실호출은 미검증이다.

월1회 공식 API 공지·버전·이용조건/법령 기준일 변경 확인 자동화를 설정했다(매월1일 오전, 한국시간). 변화 발견은 검수 작업으로 연결하며 자동 published 전환은 하지 않는다. 초등 계산문항은 매월 다시 생성할 필요가 없으며 오류 발견 시 고친다. 법령 개정 알림이 확보되면 월간 검사보다 빠르게 점검한다.
