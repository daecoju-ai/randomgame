# 학년 배치와 원리 학습 v63

962개 기존 문제를 유지하면서 서비스의 학년 배치를 조정했다. 초5 백분율 36문제는 초6으로 이동했고 과학·사회는 개념별로 초3~6에 나눴다. 영어·국어는 문장 길이와 개념 난도에 맞춰 학년을 지정했다. 영어 비교 표현 2문제는 중1에 배치했다. 배치표는 data/curriculum-placement-v63.json에 기록한다. 교육부 2022 개정 교육과정 고시를 참고한 시범 배치이며, 교과서별 학기/단원 일치와 교사 검수는 아직 완료되지 않았다.

학교 공부뿐 아니라 영어·국어 메뉴에서도 학교급과 학년을 선택한다. 문제는 낮은 난도부터 진행하며 같은 난도 안에서는 무작위로 섞는다. 원리 설명 → 별도 예제 선택 → 실제 문제 순서로 진행하고 힌트는 두 단계로 제공한다. 예제 선택은 서버 제출 이벤트에 포함하지 않는다. 예제나 힌트로 정답 문제의 보상을 늘리지 않는다. 타이머나 속도 점수를 추가하지 않았다.

학습 중 단계와 힌트 진행은 계정별 로컬 이어하기 기록에 함께 저장한다. 예전 기록에는 새 예제를 강제하지 않는다. 제출·재시도·일일/복습 보상 규칙은 그대로 유지하며 결과에 실제 지급된 금화·다이아와 유닛·스킬 강화 화면으로 가는 버튼을 보여 준다. 강화는 재화 비용을 확인하고 사용자가 실행한다. 영구 주인공 경험치 추가 지급은 이번 변경에 포함하지 않았다.

정답, 버전, 검증 지문을 바꾸지 않고 학년 메타데이터만 조정했다. 새 빌드는 더 이상 사용하지 않는 학년별 생성 팩을 정리한다. 문제 시범/검수 상태 및 출처는 유지한다.

검증: 전체 문제 962개 및 자격증 문제 검증, 172개 테스트, JS 문법 검사. 학년 배치 대상과 검증 지문 보존, 난도 순서, 별도 예제/힌트 구성을 추가 테스트했다.
