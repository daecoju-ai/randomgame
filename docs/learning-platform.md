# 학습 플랫폼 V50

진입: 이벤트 → 오늘의 학습. 본게임·기존 이벤트 전투 규칙은 변경하지 않음.

첨부 패키지의 data 구조, 두 JSON schema, 출처·이용조건 목록, Python 검증기를 병합했다. 문제 3개의 산술·문구를 확인해 reviewed + pilot로 전환했고, 마지막 문제는 숫자 선택이므로 TILE_CHOICE로 정정했다. 기존 ID는 유지하고 버전 2로 올렸다. 인간 검수 전 시범 콘텐츠임을 UI에 표시하며 정식 공개 published 단계와 구분한다. 교육과정 분류는 starter_map이며 공식 성취기준 완전 대조를 완료했다고 주장하지 않는다.

지원 엔진: TILE_CHOICE/TARGET_SELECT/MULTIPLE_CHOICE → 숫자·아이템 타일 이동; TILE_SEQUENCE/ORDERING → 순서대로 단어 타일 이동. legacy multiple_choice/tile_order는 선택 게임으로 호환. MATCHING은 확장 예약이며 현재 자료에는 사용하지 않는다. 플레이어는 타일을 누르면 길을 따라 이동하며 키보드 화살표도 지원한다. 오답은 즉시 패배시키지 않고 연속정답만 초기화한다.

Git의 data/questions → scripts/build-learning.cjs → public/learning-data/manifest + 과목별 JSON. 학습 진입 전에는 learning-entry.js만 읽고 나머지 코드·문제는 지연 로딩한다. 클라이언트는 GitHub API를 호출하지 않는다. 배포 빌드에서 validate_questions.py로 ID, 필수값, 타입, 학년, 과목, 난이도, 정답·보기, 출처, 이용조건, 교육과정 domain, 상태, 버전을 검사한다. 시범 reviewed 또는 published 원본 문제만 loader가 제공한다.

Supabase private.learning_profiles/mastery/sessions/rewards에는 프로필·진도·풀이 선택 이력·중복 보상 기록만 저장한다. 문제 본문·보기·해설을 복제하지 않는다. 세션별 정답 접두부 해시를 저장하고 서버가 Git 문제에서 만든 메타데이터 fingerprint를 검증한다. 새 문제/버전을 보상 대상으로 추가할 때 scripts/learning-platform.sql의 fingerprint 허용 목록도 검토 후 갱신해야 한다. 클라이언트 correct/보상액 입력은 받지 않는다. 인증된 소유자 + 세션 잠금 + KST 날짜·과목 유일키로 같은 문제 재호출, 새로고침, 복습, 동시 요청에 중복 지급하지 않는다. 보상: 수학·영어 각 하루 첫 완료 금화 30, 다이아 1. 최대 기록 세션 100회/일, 세션 2시간 만료. 풀이 후 재접속 시 동일 기록으로 복구할 수 있다. 관측 이벤트로 학습을 검증하나 사람이 실제 들었는지/자동화 여부를 완벽히 판별하지는 않는다.

첫 시도 정답률 = 오답 없이 완료한 세션 / 완료 세션. 오답 횟수와 마지막 버전·최근 날짜·연속 정답을 별도 보존한다. 출제는 오답률에 가중치를 주고 직전 문제 반복을 피한다. 중도 종료도 세션으로 남으며 완료만 통계와 보상을 갱신한다.

영어는 Web Speech API의 설치된 en-US/en-GB 음성을 우선 선택하며 재생 완료 이벤트를 듣기 기록으로 남긴다. 새 외부 TTS 호출·API 키·요금 없음. 기기 음성 이용조건·발음 품질은 OS/엔진에 따라 다르므로 별도 서비스의 상업 이용권이나 본토 화자 품질을 보장하지 않는다. 녹음된 외부 음성 재배포 없음. 음성 부재·실패는 체험으로 안내하고 영어 보상 조건을 충족시킨 것으로 처리하지 않는다. 영어 첫 시범문장은 beginner 어휘 + want-to 문법 + 5단어로 Level 3. 공식 학교 교육과정 매핑 완료를 주장하지 않음.

외부 데이터: sources.json/licenses.json은 원 패키지 정책과 출처를 유지. 한국어기초사전/표준국어대사전/법령/Q-Net은 현재 자동 수집하지 않는다. 키는 .env.example 이름만 추가하고 실제 값은 서버 비밀 저장소에서 관리한다. 국어·법률·자격증은 준비 중으로 표시. 법률 확장 시 law_name/article_id/effective_date/data_checked_at/version 및 원문과 자체 설명을 구분. 멀티미디어·기출문제·교과서 문장 수집은 별도 허락이 확인되기 전 금지.

오프라인: 받은 manifest/과목 JSON만 ff-learning-v1 Cache에 저장. 계정 기록 저장 실패는 학습 화면 내부에서 처리하며 결과와 동일 요청 ID를 계정별 로컬에 보관해 재전송. 기존 본게임의 저장/전투는 대체하지 않는다. 완전 오프라인 계정 학습은 서버 세션을 새로 시작하지 않으며 비회원 체험으로 플레이 가능.

검증: 기존 게임 142개 + 학습 6개 자동 테스트. 운영 DB에서 임시 합성 계정 생성 후 transaction rollback으로 수학 시작·오답·프로필·재조회·일일 보상·재호출·위조 문제 거절과 영어 듣기 조건을 확인. 실제 이용자 계정에 테스트 보상을 지급하지 않음. SQL 내부 테이블은 RLS + 직접 권한 철회, 인증 소유자 검사 후 private 함수로만 접근. 공개 wrapper는 SECURITY INVOKER.


## V51: 반복 보상과 무료 운영
- GitHub: 문제·교육과정·이미지·스키마·정답·해설. Vercel 정적 배포 및 브라우저 캐시, 문제 API는 Supabase에 저장하지 않음.
- Supabase: 인증, 프로필, 문제별 누적 통계, 완료 ID와 지급 결과만 유지. 새 완료의 상세 이벤트는 저장하지 않고 정답 접두부 해시는 즉시 비움. 재시도 멱등성을 위해 완료 ID는 삭제하지 않음. 기존 기록은 소급 삭제하지 않음.
- 수학/영어 과목별 KST 하루 첫 완료 30금화+1다이아. 이후 새 세션 완료마다 1금화, 횟수 제한 없음. 같은 완료 요청 재전송은 최초 지급 결과만 반환하며 다시 지급하지 않음. 듣기만 반복해도 지급되지 않음.
- 완료 응답에 해당 문제 진도를 함께 반환하여 별도 학습 load 조회 1회를 제거. 기존 지갑 재조회는 유지.
- 무료 플랜 공식 기준 확인(2026-10-04): DB 500MB, 월 활성 사용자 50,000, egress 5GB. 현재 DB 약14MB, 학습 약224KiB. 무료를 보장하지는 않으며 활동량·완료 ID 축적량에 따라 모니터링 필요. 참고 https://supabase.com/pricing
- 유저 개인정보·재화는 GitHub에 올리지 않음. 장기 보관 세션 삭제에는 재요청 방지용 서명 토큰/만료 정책이 먼저 필요함.
