# 학습 허브 및 API 검증 문제 확장

학습 허브는 **공부할 분야**(학교, 영어, 국어·어휘, 자격증, 생활법률)와
**다른 활동**(드라이빙 체험, 일일 이벤트·미션)으로 나눈다.
학년과 과목 → 문제 원정 시작 순으로 선택한다. 자주 공부할 과목 설정은 접을 수 있다.
드라이빙은 문제 목록에서 분리하며, 중단한 학습이 있으면 이어서 학습을 표시한다.
모바일에서 입력과 버튼이 임의의 가로 페이지로 흩어지지 않도록 기본 세로 스크롤을 쓴다.

## 추가 문제

초등 1~6학년 수학 자체 제작 문제 **580개**를 추가했다. 기존 286개를 포함하면 **866개**다.
1학년 80개, 2~6학년 각각 100개다. 계산뿐 아니라 문장제, 빈칸, 규칙, 길이와 시간,
자료 합계, 각도, 넓이, 평균, 분수의 양, 백분율, 비례배분, 부피 등을 포함한다.
문항과 해설은 원본 저작물이며 기출문제를 가져온 것이 아니다.

`python3 scripts/expand-learning-api.py`는 math.js REST API에 식을 묶음으로 전송한다.
반환된 정답을 별도의 Python 유리수 계산과 대조한다. 불일치, 누락, 오류가 있으면
문제 파일을 저장하지 않는다. 키나 사용자 정보를 전송하지 않는다.
API 성공 응답과 식은 `data/references/mathjs-v61-verification.json`에 보관한다.
`--offline`은 이 응답을 재검증하여 동일한 문제를 재생성한다. 오프라인 모드는 새 API 호출이 아니다.

학년 분류와 교육과정 연결은 내부 시작 지도 기준이다. 계산 정답의 프로그램 검증과
정식 교육과정·난이도·표현에 대한 사람의 검수는 구분한다. `reviewed` + `pilot`,
`human_publication_pending: true`를 유지하며 정식 검수 완료로 표시하지 않는다.
국어 사전·법령·Q-Net API 문항 수집이 완료됐다고 주장하지 않는다.

기존 `/api/learning`은 배포된 문제은행에서 문항을 찾고 정답 증명을 생성하므로
추가 문항도 동일한 로그인·보상 흐름을 사용한다. DB에 문제 본문을 중복 저장하지 않는다.

검증: 빌드·문항 및 자격증 검사·자동 테스트 167개 통과. 추가 580문항 모두
운영 DB의 롤백 테스트에서 시작·완료·보상을 확인했다. 서버 허용 정답 증명을
확장한 마이그레이션과 재검증 SQL도 함께 저장한다.
