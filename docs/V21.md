# V21 · 정령의 전당

참고 이미지의 큰 행동 버튼, 카드 단위 보상, 명확한 성장 목표를 기존 정령 디자인에 맞게 적용했다.

- 로비: 영웅 미리보기, 금화/다이아 지갑, 큰 전투 시작 버튼, 유닛 성장/출석·미션/부적·상점 메뉴.
- 도감: 이름 및 속성 검색, 단계/레벨/강화 가능 우선 정렬, 검색 결과 수와 강화 가능 수, 잠금 상태. 모바일에서는 목록을 먼저 보여주고 선택 시 상세로 이동한다. 필터 내 좌우 순환은 유지한다.
- 성장: 다음 진화/전용 스킬/각성 목표와 남은 레벨을 표시한다. 레벨업 버튼을 긴 스킬 목록보다 위로 이동하고 글자 크기를 확대했다.
- 결과: 금화, 다이아, 달성 미션을 구분한다. 다이아 카드는 전투 및 이번 정산의 미션 다이아 합계이며 미션별 보상도 따로 표시한다. 정산 중/실패 상태에서는 이전 보상 수치를 재사용하지 않는다.

전투 수치, 유닛 능력, 합성 확률, 과금 정책, 인증 정책은 변경하지 않았다. 인증메일 수신 및 실제 가입 완료는 이번 화면 검증 범위에 포함되지 않는다.

검증: 69개 Node 테스트, JS 구문 검사, Chromium에서 360×640 / 390×844 / 1280×900 화면, 검색/빈 결과/정렬/성장 목표/좌우 탐색/보상 합계 및 가로 넘침 확인. 검증 환경에 한글 폰트가 없어 한글 문자열은 DOM 검증으로 확인했다.
