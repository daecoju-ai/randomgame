# Play 스토어 등록 초안

게시 전 실제 빌드와 일치 여부를 확인한다. 현재 광고·인앱결제는 구현되어 있지 않다.

- 앱 이름: 운명의 대장간
- 간단한 설명: 정령을 소환하고 조합하세요. 배치와 진화로 완성하는 전략 디펜스!
- 제안 카테고리: 게임 / 전략
- 최초 배포 제안: 무료, 광고 없음, 인앱결제 없음
- 개발자 표시명·고객지원 이메일·대상 연령: 운영자 확정 필요

## 자세한 설명

소환한 정령을 어디에 배치하고, 어떤 모습으로 진화시킬까요?
운명의 대장간은 유닛의 속성과 사거리를 활용해 몬스터의 공세를 막는 전략 디펜스 게임입니다.

■ 여섯 속성, 서로 다른 전투 방식
불의 광역 공격, 물의 빙결, 땅의 둔화, 바람의 공격속도, 전기의 감전, 암흑의 치명타를 조합하세요.

■ 소환에서 최종 진화까지
1~4단계 유닛을 성장시키고, 공격형과 지원형 최종 유닛을 활용하세요. 최종 유닛은 레벨에 따라 추가 스킬과 강화 효과를 해금합니다.

■ 특별 유닛을 향한 랜덤 조합
4단계 유닛 세 개를 재료로, 해금한 특별 유닛 중 하나를 획득하세요. 조합 전 획득 가능한 유닛을 확인할 수 있습니다.

■ 전투 밖에서도 이어지는 성장
금화로 유닛을 키우고 다이아로 특별 유닛과 스킬을 강화하세요. 보유 효과를 주는 부적, 출석 보상, 장기 미션으로 다음 전투를 준비하세요.

계정 기능과 서버 보상 이용에는 인터넷 연결이 필요합니다.

## 등록 이미지 제작 목록

- 아이콘: public/icons/icon-512.png를 후보로 검수. 스토어용 PNG 규격·투명도 확인.
- 피처 그래픽: 1024×500, 게임명과 실제 유닛을 사용해 별도 제작 필요.
- 스마트폰 스크린샷: 실제 Android 앱에서 최소 2장, 권장 5장 촬영.
- 권장 장면: 전투 배치 / 최종 진화 / 도감 스킬 / 부적 / 결과 보상.
- 경쟁사 이미지, 개발용 화면, 작동하지 않는 기능은 등록 자료에 사용하지 않는다.
