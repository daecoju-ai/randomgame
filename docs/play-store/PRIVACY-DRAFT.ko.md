# 개인정보처리방침 작성 초안 — 게시 불가

운영자 이름·연락처·보유기간·처리 위치가 미확정이다. 이 문서는 실제 개인정보처리방침 URL을 대신하지 않는다.

## 확인된 처리 흐름

|정보|목적|처리 경로|
|---|---|---|
|이메일, 비밀번호, 사용자 ID|회원가입, 로그인, 계정 복구|게임 인증 API → Supabase Auth|
|인증 세션 쿠키|로그인 상태 유지|브라우저 및 서버, HttpOnly 쿠키|
|유닛 성장, 재화, 부적, 출석, 미션, 전투 결과|게임 진행 저장, 보상 계산, 중복 지급 방지|게임 API → Supabase 데이터베이스|
|기기 내 게임 설정과 진행 상태|게임 실행 및 사용자 설정 유지|브라우저 저장소|
|접속 정보와 서비스 로그|호스팅 운영·오류 조사|Vercel·Supabase 설정 및 실제 보유 항목 확인 필요|

비밀번호는 인증 서비스가 처리한다. 평문 보관이나 운영자 열람 기능을 만들지 않는다.
현재 AdMob 및 결제 SDK는 연결되어 있지 않다. 향후 도입 시 수집 항목과 고지를 다시 검토한다.

## 게시 전에 운영자가 확정할 항목

1. 운영 주체, 개인정보 문의 담당자, 이메일, 시행일.
2. 항목별 보유기간과 계정 삭제 시 처리기간. 로그·백업에 남는 기간과 예외 사유.
3. 실제 호스팅 지역, 위탁·국외 이전 해당 여부와 필요한 고지.
4. 대상 연령과 아동 이용 방식. 운영 정책 없이 임의로 연령을 확정하지 않는다.
5. 열람·정정·삭제·처리 제한 요청 방법과 본인 확인 절차.
6. 공개 HTTPS 개인정보처리방침 페이지 및 게임 내 진입 링크.

## 계정 삭제 구현 인수 조건

- 게임 설정/계정 화면과 외부 웹 페이지 양쪽에서 삭제 요청을 시작할 수 있어야 한다.
- 외부 페이지에 앱 이름과 처리 범위·기간을 명확히 표시한다.
- 인증 확인·재인증·최종 확인 후 처리한다. 다른 사용자 ID를 입력해 삭제할 수 없어야 한다.
- Auth 사용자와 진행도, 재화, 부적, 출석/미션, 이벤트 기록의 관계를 확인해 정리한다.
- 삭제 실패/재시도/완료 상태와 세션 폐기를 검증한다.
- 관리자 비밀키를 브라우저나 저장소에 넣지 않는다.
- 현재 삭제 기능은 미구현이며 출시 차단 항목이다.

## 데이터 보안 설문 초안

이메일 → 개인정보/이메일 주소, 사용자 ID → 개인정보/사용자 ID,
게임 진행·전투 기록 → 앱 활동 관련 항목으로 검토한다.
서버 로그의 진단·식별자 분류는 실제 설정을 조사한 뒤 확정한다.
수집/공유 여부, 필수/선택, 삭제 가능 여부는 각 항목별로 작성한다.
서비스 제공자 이용을 무조건 제3자 공유로 분류하거나, 웹앱이라는 이유로 수집 없음으로 기재하지 않는다.
