# V22 · 첫 모험과 부적 공방

## 적용 내용

- 유닛 정보는 비모달 패널로 열며 전투 일시정지 상태를 변경하지 않는다. 표시 수치는 패널을 연 시점 기준이다.
- 쉬움이 로비 기본 선택. 보통은 기존 몬스터·경제 수치를 유지한다.

|항목|쉬움|보통|
|---|---:|---:|
|몬스터 체력|60%|100%|
|이동속도|80%|100%|
|시작 코인|120|80|
|웨이브 코인|12|8|
|전투 금화|70%, 내림|100%|
|보스 처치 다이아|1개|2개|

두 모드 모두 30웨이브이며 미션 누적에는 동일하게 포함된다. 초기 튜닝안으로, 신규 계정 실플레이 완주율을 보고 조정해야 한다. 서버는 시작할 때 모드를 저장하고 보상 계산에 사용한다. 클라이언트 전투 수치 보고를 검증하는 기존 방식은 유지되며 완전한 서버 전투 시뮬레이션은 아니다.

## 클릭 수령

출석은 당일 카드, 미션은 달성한 각 보상, 전투는 결과 화면에서 수령한다. 계정 전투 보상은 서버에 보관되며 재접속 후 출석·미션 화면에서도 받을 수 있다. 미수령 전투 보상이 있으면 새 전투는 시작하지 않는다. 과거 지급한 보상은 회수하거나 다시 지급하지 않는다. 중복 클릭/동일 요청 재시도는 중복 지급하지 않는다.

비회원 보상은 결과 화면에서 받아 브라우저 저장에 반영한다. 수령 전 새로고침/브라우저 종료에 대한 복원은 아직 제공하지 않는다.

## 부적 31종

기존 19종 보존 + 속성별 신규 2종씩 12종 추가. 기존 1~5성 중복 수집 체계는 보존하며 별도로 Lv.1~20을 다이아로 강화한다.

- 레벨 효과: 기본 부적 효과 × 별등급 배율 × (1 + 0.05 × (레벨−1)). Lv.20은 Lv.1의 1.95배.
- 강화 비용: (등급 번호 + 1) × 5 × 현재 레벨. 일반/희귀/영웅/전설 번호는 0/1/2/3.
- Lv.1→20 누적: 일반 950, 희귀 1,900, 영웅 2,850, 전설 3,800 다이아.
- 합산 상한은 기존과 동일. 상한을 넘는 효과는 적용되지 않으며 화면에 안내한다.
- 부적 효과는 전투 시작 시 보유 상태와 레벨을 확정하여 해당 전투에 적용.
- 무료 출석·미션·보스 다이아 경로 유지. 난이도를 과금 여부에 따라 변경하지 않는다.
- 등급 확률은 기존 60/30/9/1% 유지, 등급 내부는 신규 포함 균등 추첨. 화면에 실제 다음 회차 확률 공개.

## Google Play 결제 구현 계획 (미연결)

현재 상점은 100/550/1,200 다이아 확정 수량의 준비 화면이며 판매하지 않는다. 가격은 미정이다.

1. 개발자 계정 승인, 앱 생성·서명·내부 테스트 패키지 준비.
2. Play Console에서 소비성 일회성 상품 `diamonds_100`, `diamonds_550`, `diamonds_1200` 생성. 가격/지역 확정.
3. TWA Digital Goods API + Payment Request API 연동의 현재 지원/요건을 실제 기기에서 확인. 필요한 Play Billing 라이브러리 버전과 Bubblewrap 브리지를 검증. 지원이 부족하면 Android 네이티브 결제 브리지로 전환.
4. 결제창의 가격은 Google 상품 상세에서 읽어 표시. 로컬에 가격/통화 하드코딩 금지.
5. 구매 토큰을 서버에 전송 → Google Developer API로 패키지·상품·구매상태·계정 매핑 검증 → 토큰 UNIQUE 제약과 지갑 트랜잭션으로 1회 지급 → 소비 처리 및 실패 재시도.
6. PENDING/취소는 미지급. 재설치·앱 종료 뒤 미처리 구매 조회와 지급 복구. 환불/철회 알림과 정기 대조 처리.
7. 라이선스 테스터로 승인/취소/보류/중복토큰/다른 계정 재사용/네트워크 중단/환불 테스트 후 판매 활성화.

필요 운영 설정: Play 앱 ID 확정, 상품 ID/가격, 최소 권한 서버용 Google API 자격 증명, 결제 알림 설정. 비밀키는 서버 환경에만 보관한다. 결제 완료 표시만으로 재화를 지급하는 임시 기능은 넣지 않는다.

참고: https://developer.android.com/google/play/billing/security
TWA 참고: https://developer.chrome.com/docs/android/trusted-web-activity/receive-payments-play-billing

## 검증 기록

단위 테스트 75개, PGlite RPC 통합 검사 통과. Chromium에서 360/390/1280px 화면, 비회원 쉬움 시작·정보 패널 중 전투 진행·클릭 보상 확인. 별도 DOM 검사에서 로그인 출석·미션·부적 강화 및 0개 보상 수령 확인.

`verify-v22-sql.cjs`는 `@electric-sql/pglite@0.3.14`, `verify-v22-ui.cjs`는 `jsdom@26.1.0`을 별도 검증 환경에 설치한 뒤 저장소 루트에서 실행한다. DOM 검사는 모의 API를 사용하며 실제 가입·결제 E2E 검증을 대신하지 않는다.
