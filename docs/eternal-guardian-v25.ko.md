# 영구 주인공 기획 — 별의 인도자 아스트라

상태: V25 첫 구현. 실제 기기와 장기 전투 밸런스는 추가 검증 필요.

## 성장과 소유

계정당 주인공 하나를 기본 지급하고 매 전투 시작 시 중앙 가까운 빈칸에 자동 배치합니다. 기존 32칸과 소환 제한을 차지하지 않으며 판매·합성 대상이 아닙니다. V26에서는 일반 유닛처럼 드래그로 이동하고, 점유된 칸에서는 일반 유닛과 자리를 교환합니다. 주인공도 배치 칸 하나를 점유하며 소환 시 중복 배치하지 않습니다.

로비에서 1~12글자의 닉네임을 무료로 설정합니다. 닉네임·사냥 경험치·Lv.100까지의 성장 능력치는 영구 저장합니다. 비회원은 브라우저에, 로그인 계정은 기존 진행 데이터와 함께 저장합니다. 전투마다 해방 게이지만 0으로 초기화하며 영구 성장 레벨은 유지합니다.

레벨은 `min(100, 1 + floor((sqrt(1 + 8 × 영구 경험치 / 10) - 1) / 2))`, 최대 경험치는 49,500입니다. 1→2에 10, 2→3에 20 경험치가 필요합니다. 완전 해방 기본 공격력은 `120 × (1 + 0.03 × (영구 레벨 − 1))`, 초당 공격 0.6회입니다.

## 경험치와 해방

아스트라가 직접 처치할 필요 없이 아군 전체가 처치한 몬스터 경험치를 받습니다. 처치 시 한 번만 지급하고 소환물·재생성 몬스터로 반복 획득하지 못하게 합니다. 웨이브 통과 자체로 경험치를 주지 않으며, 모인 몬스터를 늦게 잡으면 해방도 늦어집니다.

기본 경험치: 일반 1, 보스 12. 전투 해방 게이지는 600에서 완성됩니다. 150마다 20%씩 추가 해방됩니다. 한 웨이브 30마리 기준 일반 몬스터만 처치해도 20웨이브 종료에 100에 도달합니다. 보스 경험치는 동일 몬스터의 일반 경험치를 대체합니다.

수동 스킬로 영향을 준 몬스터를 효과 적용 후 5초 안에 처치하면 경험치 10% 추가. 소수 경험치를 누적하고, 같은 몬스터에는 한 번만 적용합니다. 배치·스킬 타이밍이 좋으면 18~20웨이브, 자동 플레이는 20~22웨이브 해방을 목표로 실제 전투 로그로 조정합니다. 처치가 부족하면 20웨이브 개방을 강제로 보장하지 않습니다. 쉬움과 보통의 경험치 기준은 같습니다.

| 해방 게이지 | 영구 능력치 회복 | 추가 능력 |
|---|---|---|
| 0 | 20% | 기본 공격·별의 격려 |
| 150 | 40% | 별빛 정화 |
| 300 | 60% | 마력 공명 |
| 450 | 80% | 수동 운명의 재정렬 |
| 600 | 100% | 지원범위 아군 상태이상 저항 |

Lv.100 이후 영구 경험치는 더 증가하지 않습니다. 해방 게이지는 영구 레벨과 별개로 매번 다시 쌓습니다.

## 지원 스킬과 밸런스 초기값

아스트라는 중립 속성의 지휘 지원형입니다. 기존 속성 전문 유닛보다 효과 수치를 낮추고 위치·대상 선택을 통해 가치를 만듭니다. HP·회복·방어 능력은 없습니다. 기본 공격은 짧은 별빛 선으로 표현하며 사거리 1.5칸, 공격속도 초당 0.6회. Lv.100 기본 DPS는 같은 성장 수준의 5단계 지원형 중앙값을 상한으로 두고, 전체 팀 기여도도 강한 5단계 지원형 한 기 수준을 목표로 합니다.

| 스킬 | Lv.100 효과 | 조작·제한 |
|---|---|---|
| 별의 격려 | 반경 2칸, 가까운 아군 최대 4기 공격력 +8% | 지속 효과. Lv.1 +2%부터 점진 증가 |
| 별빛 정화 | 범위 아군 최대 4기 디버프 하나 제거 | 자동, MP 30·쿨타임 25초. 실제 디버프가 있을 때만 사용 |
| 마력 공명 | 범위 아군 최대 4기 MP 회복속도 +15%, 6초 | 자동, MP 40·쿨타임 30초 |
| 운명의 재정렬 | 선택한 아군 한 기의 현재 스킬 쿨타임을 15% 줄임 | 수동, MP 60·쿨타임 35초. 궁극기 즉시 초기화 불가 |

지원 효과에는 해방 비율을 적용하며 공격력 지원에는 영구 레벨 성장도 반영합니다. 기본 MP는 초당 1, 최대 100이며 자동 스킬은 정화 우선, 다음 공명 순서. 수동 스킬은 MP를 공유하므로 시전 타이밍을 판단해야 합니다. 수동 대상을 누를 때도 설명창을 띄우지 않고 사거리와 대상 표시만 보여줍니다.

동일 종류 버프는 가장 높은 효과만 적용합니다. 속성 전문 지원과 아스트라 효과를 단순히 더하지 않습니다. 다수 아군·분신으로 효과가 무제한 확대되지 않도록 대상 수를 제한하고, 본인에게 지원 효과를 적용하지 않습니다. 다른 유닛의 MP·쿨타임에 적용된 최종 상한은 기존 부적 상한을 함께 따릅니다.

## 화면과 구현 순서

전투 하단에 초상화, `Lv.42 / 100`, 경험치 막대, 작은 스킬 아이콘 4개와 수동 버튼 한 개만 둡니다. 상세 성장표는 로비 주인공 화면에 둡니다. 아스트라 선택도 다른 유닛처럼 공격범위를 보여주며, 지원범위는 별도 점선으로 표시합니다.

1. 전용 주인공 타입·자동 배치·판매/합성 차단·짧은 공격 이펙트.
2. 처치 1회 지급, 경험치·해방·재시작 초기화, 수동 스킬 대상 선택.
3. 계정 기록 서버 저장과 재전송 중복 방지. 클라이언트 누적 경험치만 신뢰하지 않기.
4. 쉬움/보통 각각 자동·적극 조작·처치 지연 3조건 반복 측정. 목표 해방 웨이브 18~22, 전체 팀 기여도와 최종 보스 처치 시간 비교 후 수치 확정.

기획상 20웨이브 목표이며 플레이 테스트로 확정한 밸런스 수치는 아닙니다.

첫 구현 차이: 중앙 고정 배치, 기존 스킬 쿨타임 재정렬은 선택 아군이 지원범위 안에 있으면 그 아군, 그렇지 않으면 가장 가까운 아군에 적용합니다. 자동 공명은 MP 100에서만 사용해 수동 스킬에 필요한 MP 60을 남깁니다. 성장 데이터는 기존 클라이언트 진행 저장 검증을 사용하며 서버 검증 사냥 로그가 없으므로 조작 방지와 실제 해방 시간 검증은 출시 전에 보강해야 합니다.
