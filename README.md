# FORTUNE FORGE — 운명의 대장간

V8 `fortune_forge_v8_recipe_fix.html`을 기반으로 개선한 V13 개발 버전입니다.

## 실행

Python 3와 Node.js를 설치한 환경에서:

```sh
npm start
# http://localhost:8080
npm test
npm run check
```

외부 npm 의존성과 빌드 과정이 없는 HTML/CSS/Canvas 게임입니다.

## 이번 변경

- 청록 유적 전장, 금빛 HUD, 시작 화면, 모바일 도감 카드.
- 생성형 3D 스타일 투명 원화 60종을 전장/도감에서 공통 사용. 이미지 로딩 실패 시 Canvas 대체 렌더러 사용. T1 단순 복장 → T2 갑옷 → T3 관/문양 → T4 전설 장비 → T5 후광과 날개.
- T1 소환 풀은 바스티온·녹스·쏜·룩·엠버·프로스트 6종, 각 1/6 확률. T2~T5는 각각 12종으로 총 54종. 같은 계열 3개 조합 시 T2 네 종류 중 하나를 각 25% 확률로 획득.
- T2/T3 계열별 랜덤 조합, T4 지정 재료 조합, T5 전설 2개 조합.
- ZERO의 FROST 2개 수량 검사. 신화 조합이 실제 재료를 소모하고 실제 전투 유닛 생성.
- 조합 버튼은 항상 전체 54종 도감을 엽니다. 조합 가능한 영웅 그림을 누르면 즉시 조합. 보유 재료 그림과 수량은 컬러, 없는 재료는 흑백. 일부만 보유한 지정 재료는 컬러/부족 표시. T2/T3는 4종 각 25% 계열 랜덤임을 명시.
- 80마리 도달 패배, 마지막 웨이브의 적을 모두 처치한 후 승리, 재시작 초기화.
- PWA manifest, 192/512 PNG 및 maskable 아이콘, 서비스워커, 설치 안내.
- Vercel 정적 배포 설정 (`public` 디렉터리).

## Vercel 연결

Vercel에서 Git 저장소 `daecoju-ai/randomgame`을 가져옵니다. Framework는 **Other**, Output Directory는 **public**입니다. 빌드 명령은 필요 없습니다. `vercel.json`이 설정을 제공합니다. 이후 main 변경은 Git 연동 설정에 따라 자동 배포됩니다.

## 유닛 되팔기

전장에서 유닛을 누르면 선택 패널과 되팔기 버튼이 나타납니다. 실제 지출한 소환 코인의 50%를 정수 내림해 환급합니다. 조합하면 재료의 투입 비용이 합쳐집니다. 시작 보너스 4기는 각각 기본 소환가 10코인으로 평가됩니다. 판매 후 빈 칸을 즉시 다시 사용할 수 있습니다.

## 테스트와 한계

`npm test`는 DOM/Canvas 대역으로 실제 게임 코드를 실행해 재료 소비, 신화 생성, 비용/초기화, 승패, 배치 경계와 PWA 자원을 검사합니다. 실제 터치 입력, Android 설치, 오프라인 재실행, 시각적 레이아웃을 검증한 것은 아닙니다. 공개 배포 후 실제 브라우저/기기로 확인해야 합니다.

이 버전에는 계정, 전투 이어하기, 결제, 광고, 멀티플레이가 없습니다. 유닛 성장과 영웅 정수는 같은 브라우저의 localStorage에 저장되며 기기 간 동기화는 없습니다. 새로고침하면 전투만 초기화됩니다. 브라우저 데이터를 지우면 성장도 지워집니다. 밸런스는 개발 단계이며, 모든 웨이브 완주 난이도는 추가 플레이 테스트 대상입니다. 설명 중 원본 스킬 표현 일부는 향후 고유 스킬 확장 대상입니다.

## V11 성장 모드

시작 화면은 전투 모드와 유닛 성장으로 분리됩니다. 성장 모드에서 54종 중 유닛을 선택해 영웅 정수로 강화할 수 있습니다. 같은 캐릭터도 T1~T5 성장 레벨은 별도이며, 해당 영웅을 이후 소환/조합하면 저장된 레벨이 적용됩니다.

- 성장 Lv.1~20. 강화 비용: 현재 레벨 × 12 정수.
- 한 레벨마다 기본 공격력 +5% (합연산).
- Lv.5: 방패 기절 0.5초 / 암살 처형 기준 35% / 원거리 사거리 +20% / 화염 15% 확률 1.5배 치명타 / 번개 추가 연쇄 대상 3명 / 얼음 감속 1.2초. 실제 공격 종류에 따라 적용.
- Lv.10: 성장 보정 후 공격력 ×1.25.
- 처음 성장 기능 사용 시 정수 120개 1회 지급. 기존 V2 저장은 보존하면서 새 버전으로 이전.
- 웨이브 완료마다 정수 3개. 전투 종료 시 도달 웨이브 ×1.5 내림, 승리 시 30개 추가.
- 진행 중 전투를 나가면 이미 받은 웨이브 정수는 유지되며 종료 보너스는 지급하지 않음.
- 전투 중 강화 불가. 종료 화면에서 성장 또는 로비로 이동 가능.

검증: `npm test` 24개 케이스. 구체적으로 성장 저장/재로딩, 기존 데이터 이전, 손상 데이터 시작 보호, 레벨별 스킬 임계값, 실제 발사체 공격력, 티어별 성장 분리, 중복 보상 방지를 포함합니다.

## V12 회원가입·로그인

이메일 회원가입/인증번호, 로그인, 비밀번호 재설정, 로그아웃 및 계정별 성장 저장을 구현했습니다. 인증 서비스가 설정되지 않으면 실제 가입은 비활성화되고 비회원 플레이는 유지됩니다.

운영 설정: [회원 계정 활성화](docs/ACCOUNTS_SETUP.md). Supabase SQL 및 Vercel 서버 환경변수가 필요합니다. 토큰은 HttpOnly 쿠키에만 저장하며 API를 PWA 캐시에 포함하지 않습니다. 기존 비회원 데이터는 별도로 보존하고, 계정 첫 저장 때 가져오기 여부를 선택합니다. 실제 SMTP 발송/운영 DB 연동은 설정 후 검증해야 합니다.

## V13 사운드
사용자가 업로드한 `public/audio.js`의 Web Audio 합성 음악과 효과음을 연결했습니다. 첫 터치/Enter 이후 음악이 시작되고 소환·조합·타격·처치·웨이브·성장·판매·궁극기·승패에 효과음이 재생됩니다. 로비와 전투에 음소거 버튼이 있으며 설정을 브라우저에 저장합니다. 백그라운드에서는 타이머·재생을 멈추고 AudioContext를 suspend합니다. 재생 노드는 종료 시 해제하고, 다수 타격/처치 효과음은 빈도를 제한합니다. MP3/WAV 외부 음원은 현재 저장소에 없습니다. 회원 서비스는 기존 설정 안내의 Supabase/SMTP/Vercel 환경변수가 준비되어야 활성화됩니다.
