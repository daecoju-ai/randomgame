## 검증 상태 구분
1. `original_learning_pilot`: **출처·성취기준 미매핑**. 자동 검증 통과는 교과 검증 완료를 의미하지 않는다.
2. `moe_2022_curriculum`: **원문 링크·성취기준 코드 개별 확인 필요**. 이 문자열만으로 검증 완료라고 판단하지 않는다.
3. 검토 완료 문항만 `curriculum_mapping`에 `standard_code`, `standard_text_summary`, `source_url`, `checked_at`, `reviewer`를 기록한다. 원문 전체 복제 금지.
4. AI의 주제 유사성 판단만으로 `review_status`를 `published`로 변경하지 않는다.

## 검수 절차
- 원문에서 학교급·학년군·과목·성취기준 코드를 먼저 확인한다.
- 문항의 `learning_target`과 정답·해설이 해당 기준을 실제로 다루는지 개별 대조한다.
- 해당하지 않는 문항은 학년 배치 수정 또는 기초 연습으로 분리한다.
- 정답·해설을 검수하고 출처·검수일·검토자 기록을 남긴다.
- 그 후에만 출처 매핑 경고를 해소한다. 경고 숫자를 줄이려고 출처명을 일괄 치환하지 않는다.
