# 자격증 기초 원정 V54

- 산업안전기사 / 건설안전기사 → 과목 선택 → 해당 과목 문제만 무작위 출제.
- 자체 제작 계산·순서 문제 8개 추가. 전체 문제 40개. 공식 기출 및 전체 시험범위로 표시하지 않는다.
- 문제·정답·해설·공식 검증 데이터·출처·자격증 과목 정보는 GitHub JSON. 선택한 자격증은 기기에만 저장.
- Supabase 테이블을 추가하지 않았다. 기존 보상 함수에는 새 콘텐츠 검증용 해시만 추가했다. 문제 원문이나 개별 풀이 이력은 저장하지 않는다.
- 과목별 첫 보상 30금화·1다이아, 이후 완료마다 1금화. 자격증 안의 과목을 바꿔도 동일한 자격증 보상 범주로 취급한다.
- 시범 콘텐츠만 제공하고 사람의 정식 공개 검수는 남겨 둔다.
- 출제기준 적용기간과 월별 확인 정책은 `data/certifications/targets.json`에 보관. 서버 자동 수집·자동 공개 작업은 이번 변경에 포함하지 않았다.

검증: 155개 Node 테스트, JS 구문 검사, 40문제 스키마·출처·정답 검사 통과. 운영 DB에서 임시 계정 트랜잭션으로 40문제 시작/완료/보상 확인 후 롤백. 반복 103회에도 현재 상태 1행, 문제 이력·숙달 기록 추가 없음, 이전 요청 재사용 차단 확인 후 롤백.

API 상태는 배포 빌드의 `public/learning-data/source-status.json`에서 확인한다. V53에서 확인된 법령 제공자 오류 04 및 Q-Net HTTPS 연결 실패는 별도 해결 대상이며 이번 문제는 외부 API 성공에 의존하지 않는다.
