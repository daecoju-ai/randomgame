기존 계정, 성장, 금화, 다이아, 별, 주인공 저장을 유지하는 추가 업데이트.

- 숨겨진 행운 일반 6개: 전투마다 각 100 배틀코인. 그 전투에서 6개 모두 완료하면 최종 200 배틀코인. 쉬움/보통/비회원 동일. 각 전투 최대 800.

- 우편 개별/일괄 수령, 계정 잠금·요청 UUID·발송 출처 유니크 키로 재전송 및 다른 기기 중복 수령 방지. 만료 우편 지급 제외.
- SNS 최초 정답 이벤트 별도 2,000 다이아. 개발자 이메일 daecoju@gmail.com. 운영자가 공개 링크/이메일 수신 순서/계정 발견 기록을 확인 후 private.award_luck_event로 1명에게 발송. 앱 사용자는 운영자 함수를 실행할 수 없음.
- 일반 이미지 3종(기본/빠른/고체력), 보스 이미지 6종. HP/속도 프로필은 public/monsters.js. 기존 난이도 계수와 WAVE별 체력 증가에 곱함. 주인공/아군 HP 시스템 추가 없음.
- 30마리/20초 생성 시간을 누적하여 프레임 반올림에 따른 누락 방지.

무료 일반 4기 + 주인공 1기(+보유 선택 1기). 기본 초기 코인 보통 80, 쉬움 120. 소환 비용 10, 4회마다 +2, 최대40. 추가5기 비용52이므로 두 모드 모두 시작 코인만으로 10기 달성 가능.

WAVE1~3 각30, 총90 생성. 살아있는 수 기준30 → 같은 전투10이하. 두 미션은 순서 이벤트를 검증. 높은 체력·빠른 이동 몬스터 변경 이후도 조건수30 유지.
