## API 검증

Vercel 빌드 시 `scripts/check-learning-sources.cjs`가 환경변수 4개로 각각 작은 HTTPS 요청을 보냄. `public/learning-data/source-status.json`에는 성공/실패 및 시각만 남김. 키, 응답 원문, 키가 포함된 URL, 오류 상세를 출력하지 않음. 검증 실패가 게임 배포나 저장된 문제 플레이를 막지 않음.

- KRDIC_API_KEY: 직접 한국어기초사전 검색
- STDICT_API_KEY: 직접 표준국어대사전 검색
- LAW_API_KEY: 공공데이터포털 법령 검색 게이트웨이
- QNET_API_KEY: 국가기술자격 시험정보 `getPEList` (메타데이터만, 기출 이용권 아님)

법령 게이트웨이 승인 시작일이 2026-10-04이면 그 이전 UTC 호출은 제공기관의 적용 시간에 따라 거절될 수 있음. Q-Net 키는 해당 API 활용 승인 필요. 다른 API의 키와 호환된다고 가정하지 않음.

사전 데이터 확보는 기존 `scripts/import-learning-reference.py` 사용. 산출물은 gitignore된 `.learning-staging/`에 draft로 저장. 라이선스/의미 검수 후 자체 문제를 작성해 GitHub에 반영. 법령은 원문 버전/시행일/확인일을 대조. API 응답을 자동으로 정식 문제에 복제하지 않음.
