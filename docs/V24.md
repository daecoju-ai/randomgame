# V24 · 밝은 정령 정원과 전투 진입 복구

미수령 전투 보상이 있으면 서버의 `PENDING_REWARD` 응답이 새 전투를 막았다. 기존 클라이언트는 로비 뒤의 짧은 토스트로만 알려 시작 버튼이 무반응처럼 보였다.

이제 전투 시작 시 이전 보상을 확인하고 금화·다이아 수량과 **보상 받고 전투 시작** 버튼을 표시한다. 보상은 해당 버튼을 누를 때 수령한다. 서버 수령 성공 및 상태 재확인 이후 원래 시작/재도전 버튼을 다시 실행한다. 실패하면 창 안에 오류가 남고 같은 요청 ID로 재시도한다. 보상 확인 이후 서버에서 미수령 상태가 발견되는 경우도 처리한다. 연결 오류는 로비/결과 화면에 계속 표시되며 준비 중 버튼은 중복 클릭을 막고 완료 시 복원된다.

크림색 배경, 흰색 패널, 초록색 주요 버튼을 로비·도감·계정·출석·부적·결과·조합에 적용했다. 캔버스 전투장을 밝은 잔디, 모래길, 밝은 배치 칸으로 변경했다. PWA 테마와 캐시도 V24로 갱신했다. 경제 계산, 조합 확률 및 난이도는 그대로다.

## 검증

- `node --test --test-isolation=none tests/*.test.cjs`: 80개 통과. 새 클라이언트 테스트는 명시적 수령, 0 보상, 중복 클릭, 실패 요청 복구, 서버 상태 경합, 연결 오류, 비회원 시작을 확인한다.
- `npm run check` 및 `git diff --check` 통과.
- 실제 Chromium / Playwright에서 테스트 응답으로 계정 및 보상 서버를 재현했다. 비회원 시작 후 몬스터 출현, 수령 후 전투 시작, 오류 재시도, 360/390/430/1280px 메뉴 이동 및 가로 넘침, 페이지 오류를 검사했다.
- 운영 계정의 재화 변경이나 실제 결제를 사용한 검사는 아니다. 운영 서버 로그 조회는 권한 오류로 제공되지 않았다.
- 데이터베이스 변경은 없다. 기존 서버의 인증과 보상 지급·중복 방지 로직을 사용한다.
