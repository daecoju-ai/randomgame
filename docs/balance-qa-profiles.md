# 밸런스 QA 프로필

이 문서는 실기 플레이 전 자동 점검 기준이다. 모든 정적 수치는 GitHub 파일에서 읽으며 DB 조회가 필요 없다.

## 영구 공격력 성장 배율
공식: 1 + 0.05×(Lv-1) + 0.20×★
- 신규 Lv1 ★0 = ×1.00
- 초기 Lv10 ★3 = ×2.05
- 중간 Lv20 ★8 = ×3.55
- 후반 Lv30 ★15 = ×5.45
- 최대 Lv30 ★20 = ×6.45

이 값에 단계 기본공격력, 공격속도, 스킬, 부적, 전투 중 강화가 추가된다.

## 난이도 클리어 목표
- 쉬움: 초기 성장 계정이 W20 이상 도달하고, 반복 성장 후 W30 클리어 가능.
- 보통: 중간 성장 계정이 W20~25를 안정적으로 통과하고 후반 성장으로 W30 클리어.
- 어려움: 후반 성장 + 적절한 부적/스킬/5단계 조합이 W30 클리어 기준. 최대 성장만 강제하지 않는다.

## 실패 원인 분리
- 몬스터 누적 초과: 광역/공속/배치 문제
- 보스 생존: 단일 DPS/방어 대응 문제
- 최종 시간초과: 후반 성장 부족
- 코인 부족: 소환/조합 경제 문제

## 변경 규칙
한 번에 HP 성장률, 난이도 HP 배율, 코인 경제를 모두 다시 바꾸지 않는다. 실기 QA에서 실패 원인을 분류한 뒤 한 축씩 조정한다. `node scripts/balance-audit.cjs`로 정적 곡선을 재확인한다.
