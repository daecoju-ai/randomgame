# 학습 문제은행 출처·검증·배포 기준 (2026-10-09)

## 출처 원칙
- 초·중·고: 국가교육과정정보센터(NCIC)의 **현행 2022 개정 교육과정 성취기준**을 개념·학년 배치의 1차 기준으로 사용한다. 2026-01-21 개정 고시 등 후속 개정사항을 확인한다. 원문: https://www.ncic.re.kr/
- 국어 어휘: 국립국어원 한국어기초사전·표준국어대사전의 뜻풀이를 검증 근거로 사용한다. API·원문 재배포는 개별 이용조건 확인 전 금지.
- 법률: 국가법령정보 공동활용(https://open.law.go.kr/)의 **시행일 기준 현행 조문**과 법령이력을 대조한다. 법률 문제는 law_name/article_id/effective_date/data_checked_at을 필수로 기록한다.
- 자격증: Q-Net의 시험종목·출제기준·시험과목을 검증한다. Q-Net API를 기출문제 제공 API로 간주하지 않는다.
- 교과서/유료 문제집/기출 원문을 복제하지 않는다. 개념과 학습목표를 참고해 질문·보기·해설을 독립적으로 작성한다.

## 문항 필수 메타데이터
id, curriculum, school, grade, subject, domain, learning_target, difficulty, game_type, question, choices, answer, explanation, content_origin, source_reference, license, review_status, release_channel, version, review.

## 검증 게이트
1. 구조: 필수 키 존재, 고유 ID, 보기 중 정답 정확히 하나(순서형은 답 배열의 모든 토큰 존재), 빈 문항 금지.
2. 논리: 계산식은 독립 계산으로 검산; 단일정답형은 보기 간 중복·다중정답 여부 검사; 설명과 정답 일치.
3. 교육: 학교급/학년/과목과 성취기준 대응 확인. 같은 개념을 여러 유형으로 변형해도 학습 목표는 유지.
4. 사실: 교과·국어·법률·자격증의 권위 있는 원문과 대조. 법령은 시행일과 개정이력 재확인.
5. 저작권: 원문 복제·출처 불명 자료·라이선스 불명 자료는 보류.
6. 사람 검수: 새 문항은 draft, 자동 구조검사 통과 시 reviewed 후보, 교과 검토 후 published. **AI 작성만으로 reviewed/published로 승격하지 않는다.**
7. 변경: 원문 변경 시 version 증가, 수정 이력 기록. 오류 신고 시 즉시 비공개 또는 수정.

## 운영상 주의
현재 학습 클라이언트는 manifest에 포함된 문항을 읽어 게임에 사용할 수 있다. review_status 필터가 서버·클라이언트 전체에 일관되게 적용되기 전에는 draft 문항을 정식 검증 완료 콘텐츠로 표시하지 않는다. 학습 보상과 지식의 별 잔액/구매는 서버 검증·중복방지·계정 연동 완료 후 활성화한다.
