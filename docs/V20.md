# V20 · 성장과 전투 가독성

- 계정 재화를 금화·다이아로 분리. 최초 이용 시 기존 정수와 성장 기록을 한 번 이관한다. 일반 레벨업은 현재 레벨 × 12 금화, 스킬 레벨업은 현재 스킬 레벨 × 단계 × 2 다이아. 기존 강화는 유지한다.
- 한국 시간 기준 하루 한 번, 누적 7회 출석. 결석으로 초기화되지 않는다. 마지막 날 희귀 확정권을 지급한다. 희귀 확정권은 희귀 등급 내 동일 확률이며 일반 뽑기 보장 횟수와 독립적이다.
- 누적 사냥·보스·조합·최종진화·승리·부적·육성·출석·속성 미션. 달성 보상은 자동 지급하며 요청 ID와 지급 이력으로 중복 지급을 방지한다.
- 독/금속/시간/별/공허 5종. 각 조건을 달성하고 다이아로 영구 해금한 후 전투에서 속성에 관계없이 4단계 재료 세 개를 직접 선택해 랜덤 진화한다. 해금한 신규 유닛 내 동일 확률이며 5종 해금 시 각 20%이다. 기존 12종 확정 조합은 별도로 유지한다. 기존 12종 최종진화는 유지한다. 총 41종.
- 배치 칸 왼쪽 아래 단계 숫자 축소. 기본 MP 회복은 초당 1, 물·부적 보너스는 추가 적용한다.
- 기본 공격 모양을 속성별로 분리. 근접은 직접 타격, 원거리는 불꽃·빙편·바람 칼날·번개·독병·금속 날·시계·별·균열로 구분한다. 스킬에는 표식, 연격, 영역, 지원 문양, 낙하 예고를 적용한다.
- 유닛 짧은 탭은 스킬 상세 창을 열고 일시정지한다. 닫으면 기존 일시정지 상태로 돌아간다. 드래그는 배치를 유지한다. 도감 좌우 버튼은 현재 필터 내 유닛을 순환한다.

## 운영 범위

전투 결과는 클라이언트 집계를 서버에서 시간·상한·해금 상태로 검사한다. 완전한 서버 전투 시뮬레이션은 아니다. 실제 결제 및 광고 지급은 활성화하지 않았다. 인증된 계정 재화의 차감과 보상 지급은 서버 트랜잭션에서 처리한다. 비회원 전투는 기존 로컬 금화 보상을 유지하며 다이아 기능은 계정 전용이다. 중도 퇴장한 계정 전투는 정산하지 않는다.

마이그레이션을 먼저 적용한 후 V20 클라이언트를 배포한다. V20로 이관된 계정은 구버전 클라이언트의 성장 저장을 거부하므로 단순 프런트엔드 롤백은 지원하지 않는다. 서비스 워커는 진행 중인 전투를 보호하기 위해 기존 탭이 모두 닫힌 뒤 갱신한다.

보안 점검: private 테이블의 정책 없는 RLS는 직접 접근 차단을 위한 의도된 설정이다. 기존 `forge_talisman`의 인증 사용자 실행 권한도 본인 계정 RPC에 필요하다. [Supabase 점검 항목](https://supabase.com/docs/guides/database/database-linter?lint=0029_authenticated_security_definer_function_executable).
