# 초등 1~2학년 국어 19문항 1차 문항 품질 점검

일자: 2026-10-09

대상: `elementary-1-korean.json` 6문항, `elementary-2-korean.json` 13문항.

## 실제 점검 항목
- 19문항의 질문, 보기, 정답, 문제 유형을 확인했다.
- 단일선택형 17문항, 순서형 2문항. 보기에서 정답을 찾을 수 있는지 육안 점검했다.
- `V62-KOREAN-004`: '출발'과 '도착'을 단순한 반대말로 묻는 대신, 버스의 출발·도착 상황을 구별하는 문항으로 수정했다. 해설을 확장하고 버전을 2로 올렸다.
- 나머지 18문항의 보기에서 명백한 중복 정답은 발견되지 않았다. 이는 교육과정 성취기준 대조 또는 전문 검수 완료를 뜻하지 않는다.

## 보류된 검증
- 국어과 별책 5의 1~2학년군 성취기준 코드를 각 문항에 매핑하는 작업은 미완료.
- 단어 뜻풀이를 국립국어원 사전 원문과 일대일 대조하는 작업은 미완료.
- 문항의 `review_status`와 `curriculum_mapping`을 검증 완료로 변경하지 않았다.
